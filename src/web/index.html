Disc graph

A disc graph is the complete description of a disc as JSON: its format, label, and each session with its tracks or files. The forms on the other tabs build one for you. Write one by hand when you need something they can't express, such as a title and artist for every track (CD-Text), or your own Joliet / Rock Ridge settings. Validate checks it, and Show plan lists the exact steps before anything is written. A graph burns one disc as written: no multi-disc splitting and no transcoding.

Paths inside the graph are resolved on the server.

A free key is available at fanart.tv/get-an-api-key. It is stored on the server and never shown again.

Rusty Stick

USB sticks that are mounted on the machine running RustyDisc are found automatically. To write somewhere else (a folder you mount sticks into, or any other place), allow it here. Sticks mounted inside an allowed folder are listed too.

Anyone who can reach this page can use it. Set a login to require a user name and password.

The login is set by the RUSTYDISC_AUTH_USER / RUSTYDISC_AUTH_PASSWORD environment variables; change it there.
